# HelpingHands Demo

HelpingHands is a sleek frontend demo for a home-services matching platform where a user can post a task, choose a trusted helper, confirm completion, release payment, and leave feedback.

This project is designed as a clean, responsive prototype to showcase the user journey for smart task matching and secure payment flow in a home helper marketplace.

## Features

- Task dashboard with a job overview
- Helper selection flow with rating-based recommendations
- Assignment confirmation and task status updates
- Completion tracking for the assigned helper
- Payment release flow
- Feedback and review section
- Leaderboard-style summary
- Responsive design for desktop and mobile screens

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome

## Project Structure

- [index.html](index.html) — main app structure
- [styles.css](styles.css) — styling and responsive UI
- [script.js](script.js) — interactive flows and navigation logic

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open the HTML file in your browser, or serve the project using any static web server.

This is a frontend-only demo, so no backend or database is required.

## Deploying on Render

1. Push this project to GitHub.
2. Log in to Render.
3. Click New and select Static Site.
4. Connect the GitHub repository.
5. Keep the project root as the repository root.
6. Set the publish directory to `.`
7. Leave the build command empty for this static site.
8. Click Deploy.

## Notes

- This project is a frontend prototype and does not include a real backend or database.
- It is intended for demo and presentation purposes.
